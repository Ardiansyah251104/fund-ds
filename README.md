* investment evaluation,
* operational monitoring,

* and strategic decision making.

The project combines exploratory data analysis, visualization, preprocessing, and business classification to better understand growth potential and operational patterns within UMKM ecosystems.

# 📊 Business Classification

UMKM are categorized into several business performance classes:

| Class         | Description                                         |
| ------------- | --------------------------------------------------- |
| 🏆 Elite      | High profitability and strong operational stability |
| 📈 Growth     | High scalability and expansion potential            |
| ⚠️ Struggling | Declining operational efficiency                    |
| 🚨 Critical   | High-risk businesses with weak profitability        |

This classification simplifies business evaluation and investment analysis.

---

# 📈 Key Insights

Several insights generated from the analysis include:

* UMKM with stable profit margins and high revenue demonstrate stronger investment potential.
* Digital adoption positively impacts operational performance.
* Longer operational tenure tends to correlate with higher customer loyalty.
* Growth-class UMKM show significant scalability opportunities.
* Elite-class businesses exhibit stronger long-term operational stability.

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/kelpstones/fund-ds.git
cd fund-ds
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit dashboard:

```bash
streamlit run dashboard.py
```
